# DAMKAR TAPUT Website — Fixed Prototype

Versi ini memperbaiki masalah tampilan CSS yang tidak termuat ketika `index.html` dibuka langsung dari Android.

## Penting
`index.html` sudah memiliki CSS dan JavaScript **tertanam (inline)**, sehingga tampilan tetap bekerja meskipun file dibuka langsung dari penyimpanan HP.

Untuk GitHub Pages, struktur folder tetap tersedia:
- index.html
- assets/style.css
- assets/script.js

## GitHub Pages
Upload seluruh folder/repository, bukan hanya `index.html`.
Settings → Pages → Deploy from branch → `main` → `/ (root)`.
